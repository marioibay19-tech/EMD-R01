Update the website

Edit the announcements, organization chart and forms below. Changes are kept in this browser until you publish them:

  1. Make your changes. Use Preview on the website to check them.
  2. Click Download content.js.
  3. Open the js folder on GitHub, drag the downloaded content.js in, and click Commit changes. The website updates in about a minute.

Only people who can sign in to the website's GitHub repository can publish. Anyone can open this page, but their changes stay in their own browser.
